How to create and use objects in JavaScript

Learn how objects store data, and how to access, modify and use their properties and methods.

JavaScript is a popular programming language used to make websites interactive. An object is an important concept that lets us group related information and functions together.

2What is an object?

An object is a collection of properties and values. A property describes information about an object. A property can also contain a function, commonly called a method.

let student = {
  name: "Gokul",
  age: 20,
  department: "IT"
};

student refers to the object. name, age and department are property names (keys); "Gokul", 20 and "IT" are their values.

3How to create an object

A simple way is object literal notation. Write properties inside curly braces { }, separate them with commas, and place a colon between each key and value.

let car = {
  brand: "BMW",
  color: "Black",
  speed: 200
};
console.log(car.brand);

4Accessing object properties

A. Dot notation

Dot notation uses a dot followed by the property name. It is convenient when you know the property name.

console.log(student.name);
console.log(student.age);

B. Bracket notation

Bracket notation puts the property key inside square brackets. A string key is written in quotation marks.

console.log(student["name"]);
console.log(student["age"]);

C. The key difference: dynamic property access

Pick a notation and a property to see what each one returns.



Tip: bracket notation also works for property names containing spaces, such as student["first name"]. Dot notation cannot access that property using the same form.



5Add, update and delete properties


Assignment can add or update a property; delete removes a property.


let student = {
  name: "Gokul",
  age: 20
};
student.department = "IT"; // Add
student.age = 21;          // Update
delete student.name;       // Delete
console.log(student);

6Methods inside objects


A function stored as an object property is called a method. A method lets an object perform an action.


let student = {
  name: "Gokul",
  greet: function() {
    console.log("Hello, my name is " + this.name);
  }
};
student.greet();


Here, this.name refers to the object’s name when the method is called as student.greet().

    10Object vs. class
    

    

    Object
    A particular collection of properties and methods.
    

    Class
    A template that can be used to create objects.
    

    

    class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}
let student1 = new Student("Gokul", 20);
console.log(student1.name); // Gokul
    

    The main demonstration program uses an object literal; it does not declare a class. Here, Student is the class name, and student1 refers to an object created from that class. This is an additional concept; a class is not required for the main seminar demonstration.
    


    11Viva questions and answers
    

    What is an object in JavaScript?
    An object is a collection of properties and values, and it can also contain methods.
    

    How do you create an object?
    A common beginner-friendly way is object literal notation, using curly braces.
    

    What is the difference between dot and bracket notation?
    Dot notation uses the property name directly. Bracket notation uses square brackets and can use a variable to select a property dynamically.
    

    Can we change an object after creating it?
    Yes. We can add, update, and delete its properties.
    

    What is a method?
    A method is a function stored as a property of an object.
    

    Why does the program print undefined at the end?
    Because the department property has been deleted before the program tries to access it.

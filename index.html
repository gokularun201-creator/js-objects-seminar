02 Concept

What is an Object?

An object is a standalone entity consisting of a collection of properties (keys) and values.

• Property: Describes information or attributes (e.g. name, age, department).

• Key-Value Pair: Every property associates a unique name with a specific value.

• Method: When a property value is a function, it is called a method.

student refers to the object, with keys name, age, and department.

JavaScript Object Syntax
let student = {
  name: "Gokul",
  age: 21,
  department: "IT"
};
03 Creation

How to Create an Object

The most popular and concise approach in JavaScript is Object Literal Notation.

Rules for Object Literal:

1. Wrap key-value pairs inside curly braces { }.

2. Separate each key and its value with a colon :.

3. Separate multiple properties with commas ,.

Click "Run" on the code block to inspect the output live!

let car = {
  brand: "BMW",
  color: "Black",
  speed: 200
};

console.log(car.brand);
04 Access Notation

Accessing Object Properties

A. Dot Notation: student.name

Fast, readable, and standard when the property name is already known.

B. Bracket Notation: student["name"]

Required when keys contain spaces or special characters (e.g. student["first name"]).

C. Dynamic Property Access

Read a property stored dynamically inside a variable using student[key].

05 Manipulation

      
Add, Update and Delete Properties

      

        

          
JavaScript objects are mutable in memory:

          
• Add: Assign to an unassigned property: student.department = "IT";

          
• Update: Re-assign an existing property: student.age = 21;

          
• Delete: Remove an existing property using delete student.name;

          

            
let student = { name: "Gokul", age: 20 };
student.department = "IT"; // Add
student.age = 21;          // Update
delete student.name;       // Delete
console.log(student);

06 Behavior

      
Methods Inside Objects

      
A function stored as a property inside an object is called a method.

      

        

          
Methods enable objects to perform actions and encapsulate behavior alongside data.

          
The this keyword:

          
Inside an object method, this refers to the owner object that is currently executing the function.

          
Calling student.greet() allows the function to access this.name which evaluates to "Gokul".

        

        

          

            
let student = {
  name: "Gokul",
  greet: function() {
    console.log("Hello, my name is " + this.name);
  }
};

student.greet();

    In industry software, nearly every entity is modeled using objects:

    Store student name, roll number, department, CGPA, and semester grades in college ERP portals.

    09 Benefits
    
      
    Advantages of JavaScript Objects
    
      
    
        
    
          
    1
    
          
    Data Cohesion: Groups related data and properties in a single logical place rather than scattered loose variables.
    
        
    
        
    
          
    2
    
          
    High Readability: Makes large codebases self-documenting and easier for engineering teams to maintain and debug.
    
        
    
        
    
          
    3
    
          
    Dynamic Flexibility: Properties can be added, updated, or removed on the fly as application state shifts.
    
        
    
        
    
          
    4
    
          
    Behavior Encapsulation: Bundles methods with their corresponding data using the contextual this keyword.
    
        
    
        
    
          
    5
    
          
    Real-World Modeling: Directly mirrors physical world concepts (cars, users, bank accounts) into software architecture.
    
        
    
        
    
          
    6
    
          
    Universal JSON Format: JavaScript Objects translate natively to JSON, the universal data format of the modern web.
    
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    10 Comparison
    
      
    Object vs. Class
    
      
    
        
    
          
    
            
    
              Object (Instance)
              
    A specific, concrete collection of real property values residing in computer memory.
    
            
    
            
    
              Class (Blueprint)
              
    A reusable template introduced in ES6 for instantiating multiple objects with identical structure.
    
            
    
          
    
          
    An object literal is quick for standalone data; a class is best when generating dozens of similar objects.
    
        
    
        
    
          
    
            
    ES6 Class Instantiation
    
            
    class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

let student1 = new Student("Gokul", 20);
console.log(student1.name); // Gokul
